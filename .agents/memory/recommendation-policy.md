name: Recommendation policy
description: User-approved rules for qualifying parlay picks and notifications.

Only return picks that meet the configured minimum expected-value threshold, even if that means returning fewer picks or none. Do not restore WhatsApp notifications unless the user asks.

**Why:** The user approved strict EV filtering and said notifications are not needed.

**How to apply:** Preserve these choices when changing the recommendation pipeline or its delivery behavior.
